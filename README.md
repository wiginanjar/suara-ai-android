# SuaraAI Studio - Proyek Aplikasi Android

Proyek Android siap-compile dengan fitur:
- Bahasa Indonesia, English, dan Melayu
- Pilihan Karakter Pria & Wanita
- 7 Vibe / Emosi (Normal, Ceria, Antusias, Marah, Bingung, Sedih, Puitis)
- Kolom narasi tanpa batas karakter (otomatis memecah teks panjang & menggabungkan audio)
- Pemutar audio & ekspor langsung ke folder `Downloads/SuaraAI/` dalam format `.WAV` dan `.MP3`
- Bisa berjalan **100% Offline** memakai mesin TTS bawaan HP Android.

## Cara Mendapatkan File .APK (Pilih Salah Satu)

### Cara A: Tanpa Instal Android Studio (Build Otomatis via GitHub)
1. Buat repository baru gratis di **GitHub.com**.
2. Ekstrak file ZIP ini dan unggah seluruh isinya ke repository tersebut.
3. Buka tab **Actions** di repository GitHub Anda $\rightarrow$ tunggu sekitar 2-3 menit hingga proses *Build Android APK* selesai hijau.
4. Klik hasil build dan unduh file **`SuaraAI-Studio-APK`** berisi `app-debug.apk`, lalu instal di HP Android Anda.

### Cara B: Melalui Android Studio di MacBook / PC
1. Buka aplikasi **Android Studio** $\rightarrow$ pilih **Open** $\rightarrow$ arahkan ke folder hasil ekstrak ZIP ini.
2. Tunggu proses *Gradle Sync* selesai.
3. Klik menu atas **Build $\rightarrow$ Build Bundle(s) / APK(s) $\rightarrow$ Build APK(s)**.
4. File `.apk` siap dipindahkan dan diinstal di HP Android.
